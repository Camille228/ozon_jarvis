# 📦 OZON JARVIS — Система управления e-commerce бизнесом

**OZON JARVIS** — это система управления бизнесом на маркетплейсе Ozon, которая собирает данные, считает реальную экономику и честно показывает статус каждого показателя. Главный принцип: *«Честные данные вместо нарисованных цифр»*.

## 🛠 Технологический стек
- **Язык:** Python 3.11+
- **База данных:** SQLite (с возможностью миграции на PostgreSQL в будущем)
- **Веб-интерфейс:** Streamlit
- **API:** HTTPX (для запросов к Ozon)
- **Агент разработки:** OpenCode (AI)

## 🚀 Как запустить локально
1. Клонировать репозиторий.
2. Активировать виртуальное окружение (`.venv`).
3. Установить зависимости: `pip install -r requirements.txt`.
4. Создать `.env` (если есть реальные ключи Ozon).
5. Запустить сбор данных: `python -m app.main`.
6. Запустить дашборд: `streamlit run dashboard.py`.
