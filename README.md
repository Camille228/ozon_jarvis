# 📦 OZON JARVIS — Система управления e-commerce бизнесом

**OZON JARVIS** — это система управления бизнесом на маркетплейсе Ozon, которая собирает данные, считает реальную экономику и честно показывает статус каждого показателя. Главный принцип: *«Честные данные вместо нарисованных цифр»*.

## 🛠 Технологический стек
- **Язык:** Python 3.11+
- **База данных:** SQLite (с возможностью миграции на PostgreSQL в будущем)
- **Веб-интерфейс:** Streamlit
- **API:** HTTPX (для запросов к Ozon)
- **Агент разработки:** OpenCode (AI)

## 🚀 Как запустить локально
1. Клонировать репозиторий.
2. Активировать виртуальное окружение (`.venv`).
3. Установить зависимости: `pip install -r requirements.txt`.
4. Создать файл `.env` рядом с `dashboard.py` и вставить ключи из кабинета продавца (Настройки → API-ключи):
   ```
   OZON_CLIENT_ID=12345
   OZON_API_KEY=xxxxxxxx-xxxx-...
   ```
5. Запустить сбор данных: `python -m app.main`.
6. Запустить дашборд: `streamlit run dashboard.py`.

> 📊 Для расчёта безопасного остатка нажмите в дашборде «Обновить продажи (30 дней)». Команда `python -m app.main` теперь тоже собирает и товары, и продажи. История остатков накапливается при каждой синхронизации товаров.

> ⚠️ `.env` добавлен в `.gitignore` — ключи не попадут в репозиторий.

## 🧪 Тесты
1. Установить зависимости для разработки: `pip install -r requirements-dev.txt`.
2. Запустить тесты: `pytest`.

Тесты используют временную базу и не трогают `data/jarvis.db`.
